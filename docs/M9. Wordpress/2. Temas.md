No WordPress o conteúdo do site encontra-se separado do UI, permitindo desta forma que se altere o aspeto de um site sem muita preocupação sobre o conteúdo, pois este adapta-se depois "automaticamente" ao novo layout.

Enquanto que o conteúdo do site se encontra em base de dados, os UI do site é definido pelos temas. O tema é o elemento WordPress que define a forma como o conteúdo do site é apresentado, estando naturalmente associado ao layout pretendido para cada página. 

Existem diversos temas disponíveis para se instalar, alguns são gratuitos outros são pagos.
Podemos ter vários temas instalados no wordpress, mas apenas um deles é que pode estar ativo e será aplicado às páginas e posts já criados.

A escolha de um tema é muito importante pelo seguinte:
- Aproximação ao layout definido em termos de design
- Capacidade de se customizar.

Ver secção [[4. Customizar]] para mais detalhes.

Existe também a possibilidade de criar um tema completamente em branco e começar a construir todos os componentes a partir do zero. Através do plugin [Create Block Theme](https://wordpress.org/plugins/create-block-theme/) conseguimos criar um tema completamente personalizado.

## Instalar 

Para ver os temas instalados, ou adicionar um novo, vamos à secção Appearance no dashboard. 
![[Pasted image 20231113212233.png]]
Os temas instalados são apresentados, bem como assinalado o tema que se encontra ativo. A partir daqui podemos alterar o tema ativo para um dos instalados, ou adicionar um novo tema, através da opção `Add New Theme`.
Atenção que os temas podem ter secções específicas que podem não existir noutros, pelo que após a ativação de um tema será necessário validar se a estrutura se encontra toda ok.

O que é um bom tema?
Uma vez encontrado o tema que procuras, podes analisar mais informação sobre ele, nomeadamente os updates que tem vindo a realizar ao longo do tempo, as instalações ativas, o rating. Todas estas informações permitem obtem uma sensibilidade sobre a experiência global que os utilizadores têm sobre o tema.

## Editar

Os temas têm normalmente um componente de parametrização e edição que permite ajustar alguns pontos. Conforme a versão do tema podemos ter acesso ao `Editor` que nos permite editar as várias secções do tema, como é o caso do tema default "Twenty Twenty-five".
O tema Ollie também é muito versátil.
