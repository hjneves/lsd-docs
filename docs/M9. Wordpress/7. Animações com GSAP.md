A utilização do [[4. GSAP]] no WordPress requer um processo de instalação, que pode passar por:

- Utilização de um GUI, como o [Motion Page](https://motion.page/). Este plugin tem um custo de utilização associado.
- Integração dos scripts GSAP e do scripts das animações no wordpress. Este será o processo aqui desenvolvido.

# Integração dos scripts GSAP 

Os scripts deverão ser integrados no ficheiro do `functions.php`do tema em utilização.
Este ficheiro encontra-se em: `/wp-content/themes/twentytwentyfive/functions.php`.

A integração consiste na colocação de um bloco de código que se encontra descrito na documentação do GSAP sobre a [instalação em WordPress](https://gsap.com/resources/Wordpress/#installation) no ficheiro `functions.php`.

```php
if ( ! function_exists( 'twentytwentyfive_enqueue_scripts' ) ) :
	/**
	 * Enqueues front-end scripts for the theme.
	 *
	 * @since Twenty Twenty-Five 1.0
	 *
	 * @return void
	 */
	function twentytwentyfive_enqueue_scripts() {
		$gsap_cdn = 'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js';

		wp_enqueue_script(
			'twentytwentyfive-gsap',
			$gsap_cdn,
			array(),
			'3.12.2',
			true
		);

		wp_enqueue_script(
			'twentytwentyfive-scrolltrigger',
			'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/ScrollTrigger.min.js',
			array( 'twentytwentyfive-gsap' ),
			'3.12.2',
			true
		);

		wp_enqueue_script(
			'twentytwentyfive-custom-animations',
			get_parent_theme_file_uri( 'assets/js/custom-animations.js' ),
			array( 'twentytwentyfive-gsap' ),
			wp_get_theme()->get( 'Version' ),
			true
		);
	}
endif;
add_action( 'wp_enqueue_scripts', 'twentytwentyfive_enqueue_scripts' );
?>
```

Também podemos usar a IA para pedir esta alteração. Podemos abrir a pasta da instalação do WordPress no Visual Studio e pedir ao agente por exemplo: "can you please encode the gsap library here and add a custom-anim.js file so I can create the animations."

# Utilização

Uma vez integrado o GSAP podemos usar o ficheiro criado (`custom-animations.js`) para a definição das animações e começar a definir as animações nos componentes do site.

A partir daqui podemos usar o GSAP tal como vimos no M8, contudo, como não temos acesso direto às classes que estão a ser utilizadas nos vários blocos, uma estratégia poderá passar por atribuir uma classe própria aos elementos que queremos animar e usá-la como referência na definição dos tweens em GSAP.
Será sempre importante validar a organização dos blocos em modo de Inspect da página para esclarecer dúvidas sobre a que elementos html pretendemos chegar.

Vamos ver um exemplo.
Queremos animar esta secção onde vamos ter os dois cartões a entrar, um de cada lado até à sua posição final.

Depois no ficheirpo js das nossas animação ((`custom-animations.js`)) podemos chegar a cada um dos cartões através dos pseudo-selectores `nth-child()`.

```js
window.addEventListener('DOMContentLoaded', function () {
	if ( typeof gsap === 'undefined' ) {
		return;
	}

    gsap.from('.hero-anim > *', {
        duration: 1,
        opacity: 0,
        stagger: 0.2,
        ease: 'power2.out',
    })

    let anim = gsap.timeline()
    .from('.services-anim > div:first-child', {
        duration: 0.5,
        x: '-50vw',
        ease: 'power2.out',
    })
    .from('.services-anim > div:nth-child(2)', {
        duration: 0.5,
        x: '50vw',
        ease: 'power2.out',
    }, "<")
});

```
